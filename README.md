# keshavtej.dev

Personal portfolio for Keshav, focused on site reliability engineering, platform automation, and community work.

## Run locally

The site is static and does not require a build step. From the repository root, start a local server:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` - portfolio homepage
- `dissertation.html` - auto-remediation case study
- `css/main.css` - shared site styles
- `js/main.js` - dynamic copyright year
- `images/` and `icons/` - site assets

GitHub Pages publishes the site using the custom domain configured in `CNAME`.
