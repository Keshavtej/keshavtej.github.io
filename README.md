# keshavtej.dev

Static portfolio for Keshav, focused on systems engineering, SRE, DevOps, cloud-native work, writing, and community participation.

## Production security headers

The repository includes a root `_headers` policy for hosts that support that format. When the site is served from GitHub Pages behind Cloudflare, mirror the same values in a Cloudflare response-header rule because GitHub Pages does not apply `_headers` files.
